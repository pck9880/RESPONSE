## 세계관 / 아트 확정
- 게임명: RESPONSE. 시기 20XX, 정확한 연도와 날짜는 알 수 없음.
- 문명 붕괴 후, 주인공이 **버려진 지하철 객차 한 량**에서만 머무르는 조용한 디스토피아 생존 / 생활 / 방치형 게임.
- 지하철역 탐색/지역 확장 구조는 현재 폐기. 잠긴 양쪽 객차 문, 객차 내부 중심.
- 그래픽: APOChill 참고, 어둡고 아늑한 정착 감성 + 세밀하고 선명한 3/4 아이소메트릭 픽셀아트. 저채도 회색/남색, 시안/보라와 따뜻한 램프 조명.
- 배치: 12×5 아이소메트릭 타일 그리드, 2:1 비율, 중앙 통로 Y=2는 비워두기, 양옆 가구와 시설.
- 프로토타입 개별 PNG 11종: `assets/pixel/` (바닥 4, 침대, 독서 코너, 작업대, 주방/정수, 난방/환기, 파손 창문, 출입문). 원본 RGB/알파 손실 없이 업로드. 출처: RESPONSE Phase003 asset pack.
- `assets/layout.json`에는 각 파일의 크기, 기준점, 이동 경유 좌표가 존재. 침대 등 일부는 여러 소품이 결합된 복합 스프라이트. 개별 소품 상호작용은 추가 분리 필요.
- 주인공 외형: 헝클어진 머리, 흰색 소매 걷은 셔츠, 느슨한 검은 넥타이, 검은 바지와 신발. 원근/픽셀 밀도 통일.

## 시간 시스템 확정 (구현 예정 — 아직 프로토타입에는 미반영)
- 현실 40분 = 게임 1일. 낮 20분(게임 06:00–17:59), 밤 20분(게임 18:00–05:59).
- 24시간제 표시, 생존 001일차부터 시작. 00:00마다 생존 일수 +1.
- 게임 활성화/표시 중에만 시간 진행; 게임 종료/탭 이탈하면 자동 저장 및 정지; 오프라인 진행 없음.

## 사망 및 재시작 확정 (구현 예정)
- HP 0 시 사망. 보유 아이템/자원/객차 설비 복구 상태 초기화. 생존 1일차에 같은 주인공 재시작.
- 재시작마다 다른 조건부 시작 이벤트, 이유는 미스터리로 유지.
- 이전 회차 이벤트 도감, 사망 원인, 생존 기록은 영구 보존.

## 생존 밸런스 확정/1차 기준 (구현 예정)
- 난이도: 완만한 생존형.
- 초기 제안값: HP 100, 포만감 75, 수분 75, 에너지 70, 정신 안정 70, 기본 체감온도 20℃.
- 게임 1시간당 포만감 -1.5, 수분 -2, 에너지(깨어 있는 경우) -2.6, 정신 안정 -0.8.
- 체감온도 18–27℃ 쾌적. 저온/고온과 굶주림, 갈증, 피로 시 장시간 누적 악영향. 외로움/정신 안정 저하만으로 즉시 사망하지 않음.
- 음식 1개 → 포만감 +40, 식수 1개 → 수분 +45, 수면 중 게임 1시간당 에너지 +11 등의 기준 수치 사용.
- 객차 내부 시설: 침대, 식량/정수, 작업대, 라디오, 청소, 환기/난방, 일기 등.

## 자동 생활 확정 (구현 예정)
- 마지막 직접 조작 후 **현실 30초** 지나면 주인공이 자동 생활 시작.
- 책 읽기, 창밖 보기, 노래, 청소, 스트레칭, 앉아 쉬기, 일기, 라디오 듣기 등. 상태/기분/시간에 따른 가중치 랜덤.
- 객차 중앙 통로를 직접 걸어 시설에 이동한 뒤 각 행동별 애니메이션 실행. 4방향 걷기 등 독립 프레임 사용.
- **중요 생존 결정은 플레이어만 수행:** 먹기, 물 마시기, 잠자기, 시설 수리, 식량/식수/전력 소모.
- 미보유 물품 사용 불가. 직접 조작이 오면 자동 행동 중지. 게임/탭 비활성화 시 행동과 타이머 정지.

## 최신 실제 구현 / 주의
- `index.html`은 Phase 003 **그래픽 적용 프로토타입**으로 11 PNG를 불러와 12×5 그리드에 구성.
- 이전 Phase 002-A에서 작동 검증된 `주변 살피기 / 휴대폰 확인 / 일어나기` 버튼, HP/배터리 표시 및 `response_save_v1` 브라우저 로컬 저장을 유지.
- 시설을 클릭하면 설명을 보여주는 기능은 비소모성 미리보기. 생존 수치, 시간 순환, 자동 행동, 사망/재시작 기능은 아직 구현되지 않음.
- `preload`에서 이미지를 불러오고 `pixelArt:true`, 스케일 최근접 화소 모드 사용. 각 PNG는 약 0.3~0.35 배율 렌더링; 좌표/가림 관계는 시각 테스트 후 조절 필요.
- GitHub Pages는 HTML/정적 PNG를 서비스함. Phaser는 CDN 로딩으로 인터넷 필요.
- 기존 데이터는 브라우저별 localStorage. 서버 계정/동기화 미구현.
